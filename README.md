# Sistema de Gestion y Reservas de Hotel (Java y SQL Server)

## 1. Objetivos del Proyecto
- Desarrollar un sistema de gestion de reservas de hotel para optimizar el control y la disponibilidad.
- Implementar una arquitectura robusta mediante Java, JDBC y SQL Server 2022.

## 2. Antecedentes y Pruebas
- Perez et al. (2024): Optimizacion de procesos con Java y SQL Server.
- Gomez y Silva (2023): Evaluacion de rendimiento bajo alta concurrencia.
- Rodriguez (2025): Implementacion de JDBC para sincronizacion de inventarios.
